# scripts/ops — Utilidades operativas

Scripts manuales para operación del agente. NO son parte del ciclo automático.

- `limpiar_env.ps1`        — Limpieza de variables de entorno
- `post_restart_check.py`  — Verificación de estado tras reinicio
- `reset_spend.py`         — Reset manual del tracker DeepSeek (para casos de bug)
- `saldo_deepseek.ps1`     — Consulta saldo DeepSeek
- `verificar_encoding_script.ps1` — Verifica encoding de archivos .ps1
- `view_watchlist.py`      — Lee y muestra la watchlist actual

Promovidos 2026-09-17 desde raíz (AUDIT_PROGRESS.md, Fase 4).
